I'm a software developer from Argentina. I like software that is **small, fast and self-contained**: native apps measured in kilobytes, tools that work fully offline, and code without dependencies it doesn't need. Most of what I build lives between the metal and the browser — from Win32 and Direct2D to real-time physics in WebGL.

My favorite languages are **JavaScript, Go, C and C++**, but I'm at home in pretty much any stack — C#, TypeScript, Python, PowerShell, SQL — and I pick the right tool for the problem.

### How I build

- **Fast by default.** Startup time and binary size are features.
- **Few dependencies.** Each one has to earn its place.
- **Quiet interfaces.** Dark, frameless, no clutter — the content is the UI.

### Currently

- Working on backend services and CI/CD pipelines.
